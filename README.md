# 🎬 BuyMedya.com — Digital Media Agency

> Video production, drone shooting, web design, SEO and social‑media management — with an SMM service panel.

🔗 **Live:** [buymedya.com](https://buymedya.com)

![BuyMedya](buymedya.jpg)

A full digital‑media agency platform: it presents the agency's services and runs a self‑serve **SMM panel** where clients order and track social‑media services.

> ℹ️ This is a **showcase repository** — documentation and screenshots only. The source code is private.

## ✨ Highlights
- 🎥 Service showcase — video production, drone, web design, SEO, social‑media management.
- 🛒 **SMM panel** — order and manage social‑media services (followers, likes, engagement).
- 👤 Member accounts, orders and balance.
- 📱 Modern, responsive, dark UI.

## 🛠️ Tech stack
**PHP** · **JavaScript** · **MySQL** · SMM panel integration.
